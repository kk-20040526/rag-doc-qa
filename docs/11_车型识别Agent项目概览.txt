本项目是一个基于多模态大模型的车型识别智能体，由自训练的 51 类车型分类模型和 DeepSeek 大模型的函数调用能力组成，支持"拍照识别、资料查询、收藏管理、对比推荐"的完整业务闭环。

视觉部分是自己训练的 ResNet18 迁移学习模型，做 51 类细粒度分类：50 个目标车型加 1 个 unknown 类。训练数据是 4711 张目标车型图片加 1500 张 unknown 样本，输入尺寸 224×224，验证集 Macro-F1 达到 0.9153。

unknown 类是整个设计的关键。如果只做 50 类分类，模型对任何输入都会硬猜一个最像的车型，这在真实使用中是灾难。加了 unknown 之后有双保险：一是训练时从组外 777 类里采样负样本，让模型学会"这些都不像"；二是推理时如果最大概率低于阈值 0.40，也判为 unknown。

智能体部分有 7 个工具：classify_car 调模型识别车型、query_car_info 查车型资料卡、add_car_favorite 加入收藏、list_car_favorites 查看收藏、search_recognition_history 检索历史识别记录、compare_cars 对比两款车型、recommend_similar_cars 推荐同级别或同品牌车型。

工具之间能自动串联。用户说"这是什么车，介绍一下然后加入收藏"，模型会连续调用 classify_car、query_car_info、add_car_favorite 三个工具，不需要用户分三次说。多轮对话靠 SQLite 持久化会话和消息，用户说"那它呢"这类省略式指令时，系统能引用上一次的识别结果。

安全设计有两条。第一，低置信度不写库：识别置信度低于 0.55 时只列 Top-K 候选请用户确认，确认前不执行收藏、对比等写操作，避免错误传播。第二，密钥不入库：API Key 只从环境变量或 .env 读取，代码、配置、截图中都不出现真实 Key，交付版本只保留 .env.example 占位。

技术栈是 PyTorch + FastAPI + SQLite + 原生前端。后端提供对话接口和批量测试接口，前端是单页 Web 界面，支持上传图片、多轮提问、查看收藏夹。
